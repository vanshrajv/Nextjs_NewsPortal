# Next.js News Portal

## Run on Windows

1. Install Node.js.
2. Open CMD inside this project folder.
3. Run:

   npm install

4. Start development server:

   npm run dev

5. Open http://localhost:3000

## Routes

- `/` Home
- `/news` News listing
- `/news/newsid/1` Article 1
- `/news/newsid/2` Article 2
- `/news/newsid/3` Article 3
- `/news/newsid/4` Article 4
- `/news/newsid/5` Article 5
- `/news/newsid/6` Article 6

Demo news text is illustrative, not real reporting. Images are loaded from Unsplash URLs, so internet access is needed for them.
